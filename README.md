# WiseTrack

Telegram-бот для учёта личных финансов с веб-интерфейсом. Проект, с которого начался мой путь в DevOps — именно здесь я впервые разбирался с Docker, деплоем на VPS и настройкой контейнеров.

# Примечание

Код приложения написан с помощью AI (Claude Code). Мой вклад - это деплой на VPS, настройка Docker сети и поддержка работающего сервиса. Это был мой первый опыт работы с контейнеризацией и деплоем в целом, который и привёл к интересу к DevOps.

## Что умеет

- Telegram-бот для добавления расходов и доходов
- Веб-интерфейс (React) для просмотра статистики
- Напоминания через cron-задачу каждые 5 минут

## Архитектура

Приложение состоит из 4 контейнеров, объединённых через Docker Compose:

**API** — бэкенд на Rails, отдаёт данные для бота и веб-интерфейса. Настроен healthcheck, остальные сервисы стартуют только после его готовности.

**Web** — фронтенд на React, собирается в Docker и раздаётся через Nginx.

**Bot** — Telegram-бот на Python, подключается к API для работы с данными.

**Cron** — отдельный контейнер для периодических задач (рассылка напоминаний). Работает на базе того же Rails-образа, запускает таску через cron каждые 5 минут.

Данные хранятся через Docker Volumes.

## Стек

- **Backend:** Ruby on Rails
- **Frontend:** React + TypeScript
- **TG BOT:** Ruby
- **Инфраструктура:** Docker, Docker Compose, Nginx
